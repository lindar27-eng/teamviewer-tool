# Analyse-Tool TeamViewer SE

Interaktives Analyse-Tool zum Geschäftsmodell der TeamViewer SE (SDAX) im Zeitalter von Digitalisierung und KI.
Erstellt im Kurs „Ausgestaltung digitaler Geschäftsmodelle“ an der DHBW Karlsruhe (WDBM24B2) in der Rolle eines Inhouse-Beraterteams für die Geschäftsführung.

**Live ansehen:** https://lindar27-eng.github.io/teamviewer-tool/

## Inhalt

| Seite | Baustein | Was gezeigt wird |
| --- | --- | --- |
| Start | TeamViewer in Zahlen | Produkte, Umsatz, Marge, Kunden, Kundenbindung, ARR, Mitarbeitende |
| 1 | Steckbrief | Geschäftsmodell in fünf Dimensionen, Stärke und offene Frage |
| 2 | Digitaler Reifegrad | Netzdiagramm nach Appelfeller/Feldmann, Kriterien je Element, größte Lücken, Wettbewerb |
| 3 | Muster und Ideen | Magisches Dreieck, Muster nach St. Galler Navigator, Ideen-Board, Opportunity Map, Top-2-Ideen |
| 4a | Customer Journey | Journey-Map mit sieben Phasen, Schmerzpunkte, Maßnahmen und Wirkung auf den Reifegrad |
| 4b | Open Innovation | Einordnung, Beispiele nach Typ, Kundeneinbindung je Phase, Maßnahmen |
| 5a | Ökosystem-Rolle | Rollenkarte, Ökosystem-Diagramm, Pipeline oder Plattform |
| 5b | Plattformkonzept | Ecosystem Participation Navigator, Platform Value Canvas, Netzwerkeffekt-Simulation, Roadmap |
| Q | Quellen | alle Belege |

Die Bausteine 6 (Erlösmodell und KI) und 7 (Zielgeschäftsmodell und Maßnahmen) folgen.

## Bedienung

- **Weiterblättern:** Leiste unten oder Pfeiltasten ← → wechseln zwischen den Bausteinen. Ein Präsentations-Clicker funktioniert ebenfalls.
- **Customer Journey (4a):** Eine Phase wählt man per Klick auf ihren Pfeil, ihre Spalte oder ihren Punkt in der Kurve; darunter erscheinen die Details der Phase.
- **Präsentieren:** Button oben rechts, öffnet das Tool im Vollbild.
- **Bearbeiten:** Button oben rechts, macht Texte und Bewertungen änderbar. Änderungen werden nur im eigenen Browser gespeichert.
- **Dunkel/Hell:** Farbschema umschalten.
- **Quellen:** Jede Aussage trägt einen Quellen-Chip. Ein Klick darauf springt zur Quelle. Annahmen sind orange markiert.

## Technik

Eine einzelne HTML-Datei (`index.html`) mit HTML, CSS und JavaScript, dazu das Logo (`logo.png`).
Keine Installation und kein Server nötig: `index.html` im Browser öffnen genügt.
Die Übergänge zwischen den Seiten nutzen die View Transitions API (am besten in Chrome oder Edge).

## Hinweis

Studienarbeit auf Basis öffentlicher Quellen (Geschäftsberichte, Quartalsmitteilungen, Pressemitteilungen).
Keine offizielle Veröffentlichung der TeamViewer SE. Marken und Logo gehören der TeamViewer SE.
